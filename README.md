# 郵遞區號一下 v0.1.2

## v0.1.2｜門牌區間 fallback

主要查詢仍使用 `zip5.5432.tw`，保留：
- 3 碼
- 舊制 5 碼（3+2）
- API 可直接取得的現行 6 碼（3+3）
- 地址正規化與一鍵複製

### 新增第二層 6 碼查詢
若主要 API 的 6 碼為空白：

1. 解析縣市、行政區、路名、巷、弄、門牌與「之」號。
2. 動態讀取 `supra126/tw-zip` 的該縣市 3+3 門牌規則資料。
3. 比對巷／弄、單雙號、門牌起訖與「之」號範圍。
4. 只在最高特異度規則能得到唯一 6 碼時回填。
5. 若仍有歧義，維持空白並要求人工確認，不取第一筆、不猜值。

### 已鎖定的驗證案例
- 高雄市左營區富民路50號10樓之6 → fallback 預期 `813365`
- 高雄市左營區富民路50號 → fallback 預期 `813365`
- 高雄市楠梓區金富街113號13樓之8 → 主要 API 可直接回 `811505`；即使進 fallback，規則亦對應 811505
