# 郵遞區號一下 v0.1.3

## v0.1.3｜重疊門牌區間排序修正

v0.1.2 已能在主要 API 沒有回傳 6 碼時，用 3+3 門牌規則 fallback。
本版修正「同一門牌同時命中廣義規則與較窄專用規則」的情形。

### 修正原則
- 先比對巷、弄、單雙號與門牌區間。
- 多條規則同時命中時：
  1. 地址條件越具體者優先。
  2. 同層級中，門牌範圍越窄者優先。
  3. 若最高優先級仍導向不同 6 碼，維持空白，不猜。

### 重要驗證案例
- 高雄市左營區富民路50號10樓之6 → 813365
- 高雄市左營區富民路80號10樓 → 813313
  - 同時會命中「雙80~90」與「雙98以下」
  - 本版應優先採用較窄的「雙80~90」→ 813313
- 高雄市楠梓區金富街113號13樓之8 → 811505

重要寄件若結果可疑，仍應以中華郵政正式查詢為準。
