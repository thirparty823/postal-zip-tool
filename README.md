# 郵遞區號一下 v0.1

一個單頁小工具：貼入臺灣地址後，查詢並顯示：

- 3 碼郵遞區號
- 5 碼（舊制 3+2）
- 6 碼（現行 3+3）
- 正規化地址
- 各欄一鍵複製
- 一鍵複製「6碼＋地址」

## 使用方式

### 最簡單
直接打開 `index.html`。

若瀏覽器因為 `file://` 安全限制而阻擋跨網域 API，請用任何靜態網站伺服器開啟，例如：

```bash
python3 -m http.server 8080
```

然後開啟：

```text
http://localhost:8080
```

### 手機
部署到 GitHub Pages、Cloudflare Pages、Netlify、Vercel 等任一靜態網站服務後，
用 Safari 開啟，再「加入主畫面」即可當成小工具使用。

## v0.1 邊界

- 不主動補「里／鄰」
- 有里鄰則保留
- 不猜查不到的郵遞區號
- 地址正規化：Unicode NFKC、移除空白、`台` → `臺`、常見破折號統一
- 會用 localStorage 快取查過的地址，減少重複 API 請求

## 資料來源

查詢 API：`https://zip5.5432.tw/zip5json.py`

該服務說明其資料基礎來自中華郵政，並同時回傳 3+2 與 3+3 郵遞區號。
重要或可疑結果請以中華郵政正式查詢為準。
